Performance Metrics
  • Total Return: Overall portfolio return over the entire period
  • Annualized Return: Return normalized to a yearly basis
  • Sharpe Ratio: Risk-adjusted return measure
  • Volatility: Standard deviation of returns
  • Maximum Drawdown: Largest peak-to-trough decline
  • Win Rate: Percentage of profitable periods
Charts
  • Portfolio Value: Cumulative portfolio performance vs benchmark
  • Maximum Drawdown: Visualization of drawdowns over time
  • Cash Balance: Cash position changes
  • Transaction Costs: Cost analysis over time
